## atividade-calculadora
#Requisitos

1.Realizar operações

  - Permitir realizar operações de soma
  - Permitir realizar operações de subtração
  - Permitir realizar operações de multiplicação
  - Permitir realizar operações de divisão
  - Permitir realizar operações de raiz quadrada
  - Permitir resetar os números inseridos

2.Interface

  - Deve mostrar o resultado acima dos botões
  - Os números e os operadores devem ter cores diferentes

3.Tecnologias

  - React
  - Expo.dev
